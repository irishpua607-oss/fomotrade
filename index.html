API Collector (sa computer mo tatakbo)

Hindi tumatawag ng API ang page na ito at hindi dapat ilagay dito ang API key. Ang script sa ibaba ang kukuha ng data sa computer mo at gagawa ng CSV.

  1. Mag-sign in sa getfomoapi.fun gamit ang Google at gumawa ng API key (independent na serbisyo ito, hindi official ng Fomo; tingnan ang presyo sa docs nila).
  2. I-copy ang script sa ibaba at i-save bilang fomo_collect.py.
  3. pip install requests, tapos i-set ang FOMO_API_KEY bilang environment variable.
  4. python fomo_collect.py. Lalabas ang mga CSV sa folder na out/.
  5. I-upload ang mga CSV sa Radar (Hot Wallets) o sa Copy-Trade tab.

Hindi ko pa nasubukan ang script sa totoong API. Tingnan ang mga file sa raw/ at i-edit ang FIELDS kung kailangan. Hindi ito financial advice.
