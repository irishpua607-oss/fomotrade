Limitations: FOMO only sends large trades (positions of about $3,000 and up), so alerts are sparse. Each copied buy costs one API call for the price (250 credits), and so does each price refresh per trader with an open copy. A free key (250,000 credits per month) is only about 1,000 calls, so don't set the refresh too short. If refresh is 0, stop loss/take profit are not checked and open positions are not valued correctly. The simulation is saved in the browser and resumes automatically when you reopen the page (if "Remember on this browser" is ticked), but nothing is copied while the tab is closed. Best left open on a computer that doesn't sleep. A free key is realtime only for the first 7 days, then delayed 15 seconds. Not financial advice.
